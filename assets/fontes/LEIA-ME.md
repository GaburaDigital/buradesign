# Fontes

Fontes embutidas para o texto virar caminho de corte. Todas são livres e foram
reduzidas ao alfabeto latino com acentos do português, o que derruba cada
arquivo de algumas centenas de kB para algumas dezenas.

| Arquivo | Família | Licença |
| --- | --- | --- |
| `poppins-regular.ttf`, `poppins-bold.ttf` | Poppins, de Indian Type Foundry | SIL Open Font License 1.1 |
| `caladea-regular.ttf`, `caladea-bold.ttf` | Caladea, de Huerta Tipográfica | SIL Open Font License 1.1 |
| `mono-regular.ttf`, `mono-bold.ttf` | Liberation Mono, de Red Hat | SIL Open Font License 1.1 |

O texto completo da licença está em `LICENCA-Caladea.txt` e
`LICENCA-LiberationMono.txt`. Poppins usa a mesma OFL 1.1.

## Somar uma fonte sua

1. Copie o arquivo `.ttf` para esta pasta. Se ela for pesada, vale reduzir ao
   alfabeto latino antes.
2. Registre a família em `assets/fontes/fontes.json`.
3. Some o arquivo à lista do `sw.js` e suba a `VERSAO`.

Use apenas fontes que permitam redistribuição. Fontes compradas ou do sistema
operacional normalmente não permitem.
